## 실행 환경

각 과제는 독립된 프로젝트입니다.

STM32CubeIDE의 Existing Projects into Workspace에서 필요한 하위 폴더를 선택합니다. 각 프로젝트의 .ioc, 보드 및 배선 구성을 확인한 후 Build와 Download를 수행합니다.

## 소스 이력

2026년 11월 18일 로컬 소스 스냅샷입니다. [SOURCE_MANIFEST.json](SOURCE_MANIFEST.json)에 원본 상대 경로 및 SHA-256을 기록하였습니다. 공급업체 소스의 기존 저작권 고지를 유지하였습니다.
